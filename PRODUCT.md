# Product

## Register

product

## Users

Developers using local and hosted models to inspect, modify, and verify a codebase.

## Product Purpose

Zephyrus is a model workspace. The coding harness should keep instructions, workspace context, tool execution, and results understandable throughout a task.

## Brand Personality

Focused, direct, calm. Pure-black surfaces, white branding, restrained outlines, and self-hosted UI typography. Follow https://zephyrusweb.vercel.app/ for the brand's contour field and monochrome identity. After workspace selection, restore the logo-led welcome instead of continuing to show onboarding.

## Anti-references

Avoid marketing dashboards, decorative metrics, simulated repository state, and controls that imply capabilities the backend does not provide.

## Design Principles

- Keep workspace selection visible.
- Show actual execution state and make failures easy to inspect.
- Keep the transcript readable while offering progressive detail.
- Task starters prepare editable instructions; they never execute automatically.
- Preserve existing modes, model selection, and user preferences.
- Use one capsule shape for shell controls. Sidebar actions share an icon column, label inset, and 44px height.
- Align transcript and composer to a shared reading width. Code and tool output stay black, with borders and labeled controls; scrollbars use a neutral gray thumb.

## Accessibility & Inclusion

Keyboard-operable controls, visible focus, descriptive labels, reduced motion, responsive layouts, and text labels alongside status indicators. Target WCAG AA contrast using existing tokens.
